# 手机回复写作改进

2026-10-21，在M3上线后继续改进回复编辑器。

## 实际操作

- 手机回复卡片右上角「全屏写作」展开至整个可用屏幕；顶部显示当前话题，底部保留发布按钮。
- 「写作 / 预览」分开展示；格式按钮单独一排，字数在右侧。原文语言移到可展开的「语言选项」。图片仍可添加、移除、重试。
- 「收起」或Esc回到原回复位置，保留正文、选区、引用和上传状态；不创建第二份编辑器或重新上传图片。
- 全屏期间锁定底页滚动，原生dialog限制背景焦点；收起后恢复页面位置。跨到桌面宽度时自动收起，保留桌面阅读导航与宽布局。
- visualViewport追踪可用高度及偏移；有软键盘时更新编辑区域。缩放时回退布局视口，避免重复缩放。输入字体16px、底部考虑安全区。
- 草稿仍仅本页内存；刷新/关闭页面不会持久保存。语言重绘保留该话题该账号的全屏状态；退出账号与离开页面会移除旧编辑器及视口监听。

## 维护位置

`dist/reply-writing.js`负责布局/移动原编辑器/页面锁/恢复；`reply-writing.css`放在reading-nav.css之后加载；`reply-viewport.js`负责键盘可视区域监听。`m3-ui.js`保留提交、幂等回执、身份和草稿逻辑，presentation只调用快照回调，不负责提交。

不要复制textarea或把File存入浏览器存储。销毁顺序先将回复区域归位并解除页面锁，再销毁媒体和编辑器。旧dialog的延迟close事件必须核对实例，不能收起后来新开的dialog。成功发送的快照先清空，销毁不能回写旧草稿。
