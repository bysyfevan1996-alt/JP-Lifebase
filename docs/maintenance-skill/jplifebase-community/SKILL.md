## 保留的产品约定

- 简洁的高密度论坛：浅灰背景、白面板、深灰字、细边框；固定顶栏、独立滚动左栏、右侧单列话题卡片。不增加夸张首屏或装饰性副标题。
- **手机和电脑分别设计布局**：宽屏外壳和话题列表充分使用左栏以外的可用宽度，不套手机宽度、不加全局居中窄容器；保留桌面合理间距、字号和控件，不为适配手机强行压缩。手机独立安排顶栏、列表、公告和触控区，中等屏幕用抽屉避免固定左栏挤压内容。工具页面也分别设计桌面与手机布局，桌面保留其双栏与阅读操作密度，手机独立纵向排布。仅正文行长或账号表单可按阅读／输入需要局部限宽。CSS 与导航 JS 的断点保持一致，分别验收电脑与手机。
- 发帖、我的帖子、我的消息放左侧；小工具入口放 **左侧「内容」分组上面**；频道保留「杂谈」；「联系我们」在内容面板最下面。不要把工具移到右侧话题内容上方。
- 登录后用户可以发帖和回复。真实数据存在服务器 SQLite，不将账号、帖子或回复改成仅保存在浏览器的演示。示例话题明确标识，回复数来自真实记录，不造活跃度。
- M1首次默认简体中文，浏览器语言只建议；明确选择可保存到浏览器，登录偏好存服务器。简中、繁中、日、英、韩UI人工维护；其他明确选择的UI语言自动翻译并标识。用户帖子仍保留原文，M3已实现逐楼点击翻译；人工UI字典仍不进入机器翻译。切换不丢路由/草稿，快速切换和账号变更须隔离旧请求。
- M4「通知」使用统一站内事件，包含回复、@、引用、反应和最佳答案，支持已读与话题订阅；「收藏」仅本人可见；都不是私信。右下角是社区搜索，不是 AI 回答；联系留言只入库，尚无邮件转发。维护时按实际功能命名和解释。
- 管理画面为 `/admin`，只向管理员展示入口，所有管理 API 仍在服务端校验角色；支持统计、可恢复隐藏／置顶、普通成员禁言/封禁、举报状态处理、操作日志分页、用户列表和联系留言。自身及所有管理员账户受保护；封禁撤销会话，禁言限制内容写入。隐藏不删除帖子或回复；HTTP DELETE也改为可恢复隐藏，管理员恢复，运维命令须明确管理员操作者。管理数据不送自动翻译，其他系统语言只翻译静态界面字典。
- 工具沿用主域名路径（如 `/denkikakaku`），不拆子域名。电费数据／引擎使用 [电费维护 skill](C:/Users/byeva/.codex/skills/jplifebase-denki/SKILL.md)，普通论坛改版不用顺带更新电价。
