## 浏览与路由的实际行为

- 初次展示 12 条，继续加载每次多 6 条；这是已取回数组上的本地切片。`GET /api/topics` 当前最多返回 250 条，并非全库分页。不要宣称已实现无限服务端分页。
- 搜索只匹配标题、摘要、作者；未实现全正文／所有回复检索。热门先按回复数，随后按更新时间；置顶始终优先；待回复指回复数为 0。
- 分类 ID：`housing`、`visa`、`work`、`car`、`daily`、`site`。杂谈频道对应 `daily`。新增分类同时处理前端映射、五套字典与服务端 `allowedCategories`，不能只改标签。
- 当前浏览器话题链接是 `/#topic=<id>`，由 `app.js` 解析。服务端虽为 `/t/<id>` 返回首页壳，前端还未把该路径解析成详情，不能将它当成已可用的详情永久链接。
- `/denkikakaku` 由服务端直接返回独立工具页，`app.js` 里仍有旧工具占位分支；不要因看到占位分支而误判线上电费尚未实现。`/moving-checklist` 目前确为准备中。
- `/admin` 由服务端返回独立管理页，论坛左侧 `admin-entry` 只对管理员显示。匿名登录入口 `/account/login?return=%2Fadmin` 使用 `safeReturn` 精确白名单 `/admin`，完成登录后整页导航返回后台；不要扩展成任意外链重定向。
- 右下角 `assistant-*` 命名的组件实际只搜索已加载话题；不连接问答模型。
- 用户文本用转义后文本渲染，保留换行；不能因模板用 `innerHTML` 就插入未转义帖子正文或改成任意 HTML。富文本并非当前功能。

## 语言规则

`resolveLocale` 首次默认简中；系统语言只用于建议，明确选system时才跟随。preferences.js负责访客/账号偏好、串行写入、来源标记和过期响应隔离，language-ui.js呈现建议。不能把账号同步出的偏好当成另一账号的访客选择；支持家族 `ja`、`en`、`ko`、`zh-CN`、`zh-TW`，繁中判断包含 Hant／TW／HK／MO。其他语言以英语界面为源自动翻译。复用 `locale.js`，不要在各页面另造语言判断。

新增界面文案同步维护五套字典；`i18n.js` 后面有覆盖赋值，检查最终导出内容。人工维护的语言不应请求 `/api/translate`。用户帖子在这五种显示语言下保留原文，不能把“界面已翻译”理解为“所有帖子都要自动翻译”。

示例内容由 `seed-content.js` 按相同 ID 提供各语言版本。启动时日文种子 `INSERT OR IGNORE` 入库；改源文件不会自动覆写已存在的数据库行，直接删除种子也会在默认启动时重新插入。API 对人工示例的显示文本有按语言覆盖逻辑，原文查询则仍读已存内容。维护示例要区分显示覆盖与存储迁移，不能删正式用户数据来重置示例。

其他明确选择的界面语言自动翻译须显示标识，失败回退英语。M1前端对非人工语言的帖子请求lang=original，所有用户帖子保持原文，不随界面批量翻译；旧显式公共翻译API保留兼容。M3已有逐楼按需翻译，原文切换不代表整页界面恢复。联系留言、账号信息、会话和个人回复通知不送翻译。翻译缓存按目标语言、源语言、源文本计算hash；源文变化生成新缓存，不清空整库。

后台复用 `jlb-language` 与 `resolveLocale`，人工字典单独维护五套。其他语言只自动翻译静态界面，管理数据保持原文；联系、举报、用户邮箱不得进入翻译请求。管理内容采用 `textContent`，不插入未转义 HTML。页面缓存恢复时重新校验会话，离页清理私密画面。

后台桌面使用流式主区域与左侧分组，不设全局窄容器；手机改横向分组标签与卡片行，主要按钮约44px。隐藏／恢复和置顶操作有忙碌状态、错误与重试，状态成功后重读真实数据；后台没有永久删除按钮或伪造统计；M1用户列表有禁言/封禁确认，举报状态选择，审计筛选和继续翻页。受保护账户不提供限制操作，服务端也拒绝。

## 验证要点

顶栏登录后的账号入口只显示圆形头像，不显示昵称或黑色长胶囊；电脑/手机均保留40px点击范围、32px头像、账号名称的aria-label与原点击路由。未上传头像时继续昵称首字回退，未登录注册/登录按钮保留。此规则仅针对顶栏账号入口，不隐藏帖子作者或改动提及标识。

修改后分别检查电脑、平板与手机：至少使用宽屏 1440／1920px、平板 768／1024px、手机 320／390px，并检查 760px 和 1099／1100px 的布局边界。确认无横向溢出、导航可开关、宽屏话题区充分展开；涉及长标题、语言和账号头像时一起覆盖。不能拿手机预览作为电脑版验收。

检查相关路径的导航、搜索／分类、最新／热门、详情返回和继续加载；涉及发帖则检查独立登录页、返回意图与回复草稿。保留加载、空列表、网络错误和翻译失败状态。只做小改动时选择相关路径，不必每次重跑完整浏览器流程。截图说明实际预览尺寸；临时修改浏览器 viewport 后恢复默认。

## V1.1长帖阅读导航

`dist/reading-nav.js`控制本页正文/首批回复/最新回复/写回复与返回点；`reading-controls.js`提供按钮状态与计数校验；`reading-position.js`保存内容节点相对位置，`reading-nav.css`分别安排宽屏右卡、窄屏横排与手机布局，`reading-i18n.js`提供五语人工文案。宽屏>=1440且详情容器>=940px使用188px右侧大卡片；卡片top为calc(100% + 24px)，对齐标题下方正文顶部，不与标题顶端并排。卡片与吸顶标题同一表面移动，滚动时仍在标题下方。窄屏桌面/平板保留紧凑横栏，<=760px保留底部双按钮。容器在#detail-view，手机固定条在body；不要把底栏放进容器建立的包含块里。

reading-header.js与reading-header-state.js负责吸顶标题：桌面26→18px、手机22→16px，滚动超过主题起点后96px内连续收缩，回到顶部恢复；分类等次要信息收起。外层保留展开高度，内层视觉表面收缩，宽度改变时重测，避免正文跳动。宽屏右卡位于吸顶标题表面的下方右侧，不能恢复top:12px而升到标题区域；窄屏横栏与标题一体。话题导航全部用灰阶，含选中、计数和返回，不恢复成绿色。正文保持展开。标题回复数可点击。返回按钮在电脑上常驻，无临时位置时禁用并显示原因，有位置时高亮。返回只用于本次话题页面，不是M2持久或跨设备阅读进度。切换话题销毁监听与返回点；语言重绘保留回复草稿。短回复滚动受页面底部钳制时也须显示返回。跳转留白读真实横栏高度；仅<=760px手机输入聚焦时收起底栏；JS与CSS都须限定手机，电脑写回复时右卡/顶部横栏继续显示、返回可用。弹窗/抽屉/编辑器遮罩时隐藏。话题搜索放顶部，浮动搜索不叠底栏。

API replyWindow=first|latest分别读取前/后250条，latest在客户端仍按时间正序。first与latest均有范围提示，不能把最早250条的最后一条称作全帖最新；尚无完整中段分页。发回复的延迟成功响应只清理原话题原账号原输入节点，不影响切换到别处后的草稿。浏览器自动化点击sticky按钮可能先滚动元素，定位精度另用真实点击核实，不能据此硬编码补偿偏移。验收必须包含“长正文中点击写回复→实际聚焦输入→导航仍可见→返回原处且草稿保留”，检查宽屏右卡与窄屏横栏；仅验证查看回复再返回不足以覆盖这个问题。真实控制器回归在tests/reading-nav.test.mjs，标题单测在tests/reading-header.test.mjs；导航harness的无标题fallback不是标题联动的验收证据。CSS和真实压缩标题下的返回用浏览器分别验证，跳转需测量当前标题高度，不采用固定补偿；锚点不能包含吸顶标题本身。

node ops/check-i18n.mjs检查site/auth、admin、composer、denki五语键和占位符，以及静态t/copy引用；新增键不能靠英语fallback蒙混。主站、后台和电费页共享账户偏好控制器；前端明确切换保存账号，GET过期及账号变更不能覆盖新选择。语言变更不整页刷新，保留登录输入、草稿、回复和阅读位置。工具apex与www的登录cookie/本地存储为独立来源，不能承诺未登录跨域自动同步。




## M3 前端维护

m3-format.js抽取格式函数，新主题composer、m3-editor回复/编辑共同使用；m3-media负责回复图片文件、上传UUID和待发布状态，m3-ui负责版本编辑/冲突对照/历史/可恢复隐藏、结构引用/source、灯箱和逐楼译文。m3-i18n.js五套人工字典经app合并，新增模块也纳入ops/check-i18n.mjs扫描。保留#reply-text供导航聚焦。

回复按话题+账号保留页面内存草稿，语言/路由重绘前保存File/引用/UUID，关闭页面或刷新不保证保留。异步保存/隐藏完成回调在await列表刷新后再次检查当前话题与账号；否则旧loadDetail可能清空新路由。编辑409后不自动改expectedVersion或重提；用户显式载入最新版，保留输入并显示最新正文供手动合并，另行保存。预览切换同时更新aria-label和可见文案。

选区必须完全处于同一原文post-body，不能把译文选区当原文引用。最多6段、每段1500字符。source按ID读当前原文并显示版本差异，来源可能在first/latest未加载窗口中。翻译/原文切换后重建readingNavigation保留临时bookmark，锚点使用帖ID+段内序号；不把sticky标题当正文锚点。dialog关闭还原触发焦点；灯箱只处理校验后的站内图片URL。

回复编辑器使用独立的写作/预览标签与单排7个格式按钮；编辑历史弹窗仍使用共用工具栏。桌面与手机继续灰色吸顶缩小标题，不能重置为绿色或全局窄容器。验收两窗口冲突→手动合并、输入/图片在切语言后保留、引用隐藏不泄漏、翻译后返回和手机dialog。

## 手机回复全屏写作

reply-writing.js / reply-writing.css独立安排手机回复，样式在reading-nav.css之后。卡片右上「全屏写作」移动同一个replyHost到body下原生dialog，收起或Esc恢复原位置；不复制textarea/File/回执、不重载详情、不清草稿。语言选项收进details，字数右对齐，发布区在底部；手机16px输入和安全区，桌面保留内联宽编辑器和阅读导航。

reply-viewport.js只在展开期间监听visualViewport/窗口并合并帧，写入可见高度/偏移；缩放回退窗口，不禁止用户缩放。销毁取消帧与监听，恢复之前body样式/滚动。路由/身份切换必须移除body下dialog；延迟close核对当前实例。getReplyState保存fullscreen，成功提交的快照清空；草稿仍只是页内内存。readingNavigation重建时显式传replyInput引用，不能假定全屏input仍在root内部，否则翻译迟到重建会丢写回复入口。

验收全屏写长文→预览→编辑→收起/再展开、图片/引用/切语言保留、离开话题及返回、发送后清空、跨到桌面自动收起，以及小高度发布按钮可见。浏览器缩短视口和自动化测试不是实体手机键盘/IME验证。详情见源码docs/MOBILE_REPLY_WRITING.md。

## V1.3 编辑历史与 M4

content-time.js统一日本时区的绝对日期/时间。m3-ui里的编辑信息用time datetime，历史仍作者/管理员可见，50版本/页beforeVersion游标、当前/初版/编辑者、排版/源文本切换。历史新请求必须校验内容、账号和modal.open；原始文本textContent，不公开旧稿。

m4-ui.js负责站内通知、私有收藏、handle/@、话题订阅、新回复已查看、三种反应、最佳答案。m4-i18n.js人工五语、m4.css手机独立控件。app接入My messages与收藏、未读badge、已解决filter；过滤必须发server（LIMIT250之前），不能仅筛已加载列表。通知只是站内，不声称邮件/浏览器推送；旧messages API兼容不再作为新通知来源。

通知分页/未读/标已读从真实API读取；read-all只当前可见，迟到响应以actor+generation+modal状态隔离。badge轮询不触碰回复草稿；离route abort/关闭私有dialog，身份请求去重并能重试，logout清私有显示。通知source按ID读正文，不假定它在当前250条回复窗口中。每帖反应用IntersectionObserver靠近视口时加载，避免长帖一口气250请求；set期望反应而非盲toggle，发送期间锁按钮。最佳答案更改仅更新本地标记/列表，不重建编辑器。

全屏writer里@选择保留同一textarea并派发input；引用、上传、pending回执和语言切换不能丢失。界面不得把handle当邮箱或可改昵称，昵称和公开标识都用文本节点。跟踪的已查看是话题级事件计数，不是M2精确阅读位置。手机主要按钮约40–44px、反应紧凑灰阶，桌面主面板保持宽布局。

## M5 页面与动态目录

m5-ui/css/i18n负责/search高级检索、/u/handle公开资料、账号内独立资料设置和精确来源弹窗；m5-admin负责目录与指标。所有静态文案五语人工维护，新增模块纳入check-i18n。/t/id兼容旧hash；safeReturn只允许严格本地主题/资料/搜索路径，不扩大成任意URL。搜索结果不再经selectTopics把回复命中误过滤；路由/账号/语言变化abort或校验代数，M5清理不丢回复内存草稿。

community-directory.js维护动态目录并更新categories/topicTags；所有历史ID保留，active只约束新选择。compose-drafts接受语法合法的旧ID，不能因后台新增/停用而删本地草稿；composer刷新目录不重建正文/上传/回执。新增分类名称从translations/name取文本，不调用缺失的t(id)；找不到的历史标签可安全显示原ID。后台ID已有项只读，不提供删除旧关联。

版本化模块必须使用同一依赖URL以共用动态topicTags；测试若直接import无query模块会形成另一ESM实例，需按实际导入specifier取相同实例，不硬编码缓存版本。运营指标定义用m5手工五语，日期标UTC；资料字段保持纯文本，HTTPS链接拒绝凭据和其他协议，保存/语言重绘/身份轮询保持未保存输入。
