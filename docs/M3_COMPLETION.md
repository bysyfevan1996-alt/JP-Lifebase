# M3 内容编辑与翻译

2026-10-21。M3已完成并上线，V1.2和V1.0补记已发布。本文件记录实际能力、验证及发布；后续手机回复全屏改进见[MOBILE_REPLY_WRITING.md](./MOBILE_REPLY_WRITING.md)。

## 交付范围

- 新主题、回复、内容编辑共用Markdown格式函数；回复有安全预览、快捷键、输入法提交保护、最多5张图片及幂等发布。源语言默认und，作者可指定，不使用界面语言冒充识别结果。
- 主楼与回复有版本校验、编辑历史和可恢复隐藏。作者/管理员可编辑；历史限作者/管理员；管理员恢复。冲突保留本地输入，显式载入最新版本供对照后才更新编辑基准，仍需手动保存。
- 最多6段结构引用，每段1500字符，保存源ID/版本/摘录。服务器按原文可见文本校验，跨话题及旧版本引用拒绝；来源隐藏时摘录/作者不再公开。来源对话框按ID读取，不依赖该回复在first/latest窗口中。
- 主题与回复图片在当前页灯箱查看，可前后切换、键盘操作及返回焦点。回复图片独立post_id关联；隐藏回复或主楼时图片不可从URL绕过读取。已发布图片编辑时保留，不提供编辑中增删。
- 用户点击单条内容才翻译，五套人工UI语言也可互译。原文/自动翻译标识/目标语言/失败重试独立于界面翻译。GET列表/详情不再自动翻译用户内容；引用保留原文。
- Markdown使用同一受限AST解析和DOM安全渲染，翻译只替换文本节点，保留结构、代码、链接地址与数值；引用块不送翻译。输出占位符校验在底层缓存写入前执行。
- 缓存按内容种类/ID/版本/源语言/目标语言/规则版本隔离；供应商返回后重查内容版本和可见性；编辑或隐藏期间产生的旧结果不公开或缓存。
- 持久账号/IP每日额度与已有全局预算、并发上限、超时及同请求去重并用。UTC日期计预算，不表述为日本自然日。失败仍消耗已登记额度。个人/管理/私密信息不加入内容翻译载荷。
- 保留灰色吸顶缩小标题与桌面右栏/窄桌面横栏/手机底栏。翻译替换DOM时重建导航锚点，以帖ID+段内序号保持引用位置；异步操作校验路由、账号和内容版本。
- 回复草稿按话题和账号保存在本页内存；切语言/路由/详情重绘保留文字、引用、待上传File及上传UUID，刷新/关闭不持久化。主题单草稿沿用既有浏览器存储。

## 数据与发布

应用内部版本0.3.0，schema3。migration-v3.mjs追加主题/回复版本、回复可见性、回复图片归属、修订/引用/回复回执/翻译缓存/额度表，以及仅运营者可写的release_order。版本1/2摘要不变，旧正文/账号/图片保留。旧schema2代码不能作为schema3的自动恢复候选；安装器预演失败保留旧服务，切换后异常以前向修复或已知兼容版本处理，不覆盖数据库。

新模块community-content.mjs与content-translation.mjs接入既有同源POST策略，所有写入在读请求体后复查身份。隐藏的内容在source/history/translate/images/messages/回复数等入口均检查，topic-attachments保留旧独立测试模式兼容。

V1.0/1.2公开内容见V1.0_ANNOUNCEMENT.json与V1.2_ANNOUNCEMENT.json。使用既有管理员和固定创建UUID运营发布，重试幂等。仅站务分类按release_order排列100/110/120，不伪造发布日期，也不改普通讨论排序。V1.0明确为本次补写的V1.1之前总览。顺序调整独立审计，不能通过公开发帖参数设置。
