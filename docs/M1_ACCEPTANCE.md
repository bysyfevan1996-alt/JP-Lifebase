# M1 验收范围

用户授权：按已确认社区升级计划完成M1，并提交到专属仓库 `https://github.com/bysyfevan1996-alt/JP-Lifebase.git`。本期不实现M2–M6。

## 语言

- 没有明确选择的访客首次显示简体中文。浏览器语言仅提供建议，不自动覆盖。
- 简中、繁中、日语、英语、韩语界面人工维护；其他明确选择的界面语言保留带标识的机器翻译与失败回退。
- 账号语言存服务器，游客选择存浏览器；登录读取账号偏好，账号尚无偏好时可采用明确的访客选择。
- 切换语言不刷新整页、不离开当前话题、不丢草稿或回复；快速连续切换和切换账号时旧异步响应不得覆盖新状态。
- 字典完整性检查覆盖主站、管理、编辑器、工具及账号使用的文案；不因回退英文而掩盖缺失键。
- 本期仍不增加用户帖子跨语言点击翻译，该能力属于M3。

## 管理

- 匿名管理API拒绝401、普通成员拒绝403，不能依赖前端隐藏按钮。
- 管理员可更改普通成员的禁言/封禁状态，不能限制自己或其他管理员；不提供改角色入口。
- 禁言保留登录、阅读、账号维护和举报，阻止主题、回复、主题删除、图片上传/保留/移除等内容写入；对应接口服务端检查。
- 封禁撤销全部会话，拒绝后续登录；解封不恢复原会话。异步读取请求体/文件后再次检查当前身份和限制。
- 公开电费、联系和翻译接口保持既有匿名独立额度，不把这些入口描述为“能识别封禁者的全站屏蔽”。
- 举报状态支持open/reviewing/resolved/dismissed，保留处理人和时间；更改状态不擅自删除帖子。
- 审计可查看和按操作类型筛选，最多50条/页，通过时间+ID游标继续加载，同时间记录不漏不重。
- 限制与举报状态更新和审计在同一事务；重复操作不重复写日志。审计不复制举报正文、邮箱、密码等私密信息。

## 数据与发布

- 现有迁移版本1保持冻结，M1增加版本2。旧用户默认未禁言/未封禁、旧举报默认open。
- 原账号、密码、会话、帖子、回复、图片及电费记录保持不变；新增列和新增迁移账本项单独核验。
- 发布副本验证需要允许迁移账本追加新项，同时检查原有账本前缀完全不变；恢复验证覆盖迁移后的全库。
- 测试和截图使用隔离数据，不添加正式测试账号/帖子，不读取密钥，不发送真实邮件或请求翻译供应商。
- Git提交排除数据库、密钥、环境文件、临时发布包、私有副本及旧Sites预览元数据，保留远程初始化历史。
- 公网验证、实际release、schema、源码摘要、测试数量及Git提交在实施记录中写入实际值。
