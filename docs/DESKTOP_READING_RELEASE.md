- 展开外壳保持文档高度，动态表面吸附60px站点顶栏下方。宽屏保留灰色右侧大卡，窄桌面横栏接在实时标题高度下方。正文/回复/答案/热门/返回跳转按真实固定栏高度留白，避免目标被标题覆盖。
- 手机≤760px继续独立52px阅读栏和56px+safe-area贴底查看回复/写回复。原全屏回复表单、草稿、引用、上传回执和账号隔离沿用，不因置顶回复重建编辑器。
- `reply-highlights.mjs`全库读取同话题当前可见回复。最佳答案优先，随后最多3条热门；热门为like/thanks/helpful合计至少3次，排除最佳答案，按合计数降序、时间升序、ID升序稳定排序。隐藏主题/回复及跨话题答案排除。
- 详情原first/latest最多250条时间窗口保持，窗口外精选独立由`featuredReplies`返回。客户端按ID合并去重，移动同一个回复节点，原编辑、历史、翻译、引用、反应事件保留。
- 原始楼号按同话题created_at/id顺序计算，隐藏回复仍占号；主楼#1、回复从#2起。置顶不改楼号，不能用可见数组索引或DOM位置定位内容。M3/M4继续用真实内容ID关联。
- 更改最佳答案成功后立即移动原节点并更新导航；热门名单重新打开话题/重新请求详情时刷新，本次反应操作不承诺实时重排。导航新增最佳答案/热门回复入口，仅有对应内容时显示。
