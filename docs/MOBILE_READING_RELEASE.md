# 手机帖子阅读布局

用户已确认设计 demo 并授权上线。实现位置：dist/mobile-reading.js、mobile-reading.css，配合 reading-header/nav 与现有 M3 回复写作模块。应用 0.5.1，schema 5 不变；不修改电价数据与其他未完成的 updater 工作。

## 布局与真实功能

- 760px 及以下的帖子页使用 52px 单行工具栏，含返回、品牌/滚动后话题标题、书签和话题选项。首页、搜索页及电脑原有外壳保持。
- 完整文章标题随正文滚走；作者与头像同一行，正文使用两侧 16px 留白，不再长期占用头像列。正文 16px、行高 1.86。
- 标签视觉约 24px，触控高度仍 44px；收藏改为透明背景的图标按钮。
- 通知与收藏整块原控件移动到原生选项面板，保留同一个节点、事件、请求和账号边界。工具栏仅代理真实书签按钮，MutationObserver 同步加载、禁用与选中状态；请求错误在面板保留重试。切回电脑后原节点归位，离开帖子关闭面板、撤销监听。
- 查看回复/写回复操作栏贴合屏幕底边，无外围圆角、边距和阴影，预留 iPhone 底部安全区及正文空间。段落返回继续使用原实现。
- 手机“写回复”直接打开原全屏编辑器；同一 textarea、引用与图片回执随表单移动。收起恢复原滚动位置；电脑继续定位行内编辑器。发布成功后仍按原逻辑清空已发布草稿，未发布草稿仅页内内存。
- 五套人工界面字典增加话题选项文案。其他界面语言仍沿用既有标注翻译。
