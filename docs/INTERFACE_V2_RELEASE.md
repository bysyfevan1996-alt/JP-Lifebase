## 实现

- `interface-v2.css` 为正式站统一布局，桌面使用社区侧栏与可用正文宽度，手机使用 54px 导航和讨论/搜索/通知/我的底部入口。移动原语言选择节点到手机侧栏，保留同一偏好逻辑。
- 已登录 `/account` 独立为账号概览、公开资料、偏好、账号与安全三组，不再复用 440px 登录卡片或显示登录/注册标签。头像继续独立裁切保存，表单未保存输入通过原 M5 草稿保留。
- 文本输入样式排除 checkbox/radio；隐私复选框有独立尺寸，公开资料关闭时禁止并取消近期活动。手机资料保存区位于主导航上方；加载/保存期间禁用，错误与成功状态可读。
- `/api/me/profile` 兼容旧五字段并允许可选昵称。2–40 字、保留名称/重名/控制字符校验；身份与封禁在读取正文后和事务内复核。昵称、本人话题作者展示名、资料在同一事务更新，handle/角色/邮箱/正文版本和时间保持；事务失败全部回滚。旧客户端不传 name 仍可保存。
- `/notifications`、`/bookmarks`、`/my-topics` 为真实独立页面；站内事件、已读及分页共用原接口，离页/换账号取消旧请求和私有显示。通知直接进入话题，避免旧通知弹窗叠原文弹窗。三条页面路由 noindex，匿名 API 继续 401。
- 全站搜索入口统一到 `/search`，搜索设置进入同一高级筛选；筛选保留 URL 条件。首页不默认显示大横幅，保留原明确选择的横幅设置。
- 正文标题在内容中滚走，桌面宽屏灰色话题导航独立置于正文顶部，较窄桌面使用操作行；手机保留原贴底查看回复/写回复和同一全屏编辑器。跳转偏移只计仍固定的栏，不计已滚走的标题。
- 新静态文案均有简中、繁中、日、英、韩人工版本；语言与阅读字号分开，字号只调整帖子正文并保存当前浏览器。

演示数据和演示保存行为未部署为真实功能。
