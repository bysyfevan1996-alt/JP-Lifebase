# V1.1 阅读导航修正

2026-10-21，用户反馈电脑点“写回复”后右侧消失，并要求改善视觉。随后要求桌面和手机主题区一起吸顶、上滑时标题缩小、导航改为灰色。最终应用版本0.2.3，schema2和电费v5不变。

## 原因和修复

旧控制器对所有屏幕的回复框聚焦都加reading-keyboard-open，而CSS同时隐藏桌面导航与手机底栏。此前的验收确认过“跳到回复→返回”，但漏了“写回复→输入框聚焦→返回”的桌面组合；之前宣称整体通过不充分。

修正为仅手机宽度<=760px的输入聚焦触发底栏收起，CSS同样只在手机规则中处理底栏。桌面右栏和紧凑横栏在输入时继续显示。返回按钮常驻：没有临时位置时禁用并提供说明，有位置后明确高亮；返回消费本次位置后仍保留按钮。草稿不清空。

## 视觉调整

- 宽屏右侧改为188px轻描边导航卡，图标、正文/回复状态、回复计数、返回及主要操作分组；不增加全局窄容器。
- 较窄桌面/平板的操作横栏与主题标题放进同一个吸顶组件，避免孤立操作条。手机为留出安全区的浮动操作条，独立安排图标、数量与写回复按钮。
- 两端标题均随滚动连续缩小：桌面26→18px，手机22→16px；分类等次要信息逐渐收起，回到顶部自然展开。长标题限制可见行数，原文和语义标题仍保留。组件以展开高度占位，视觉层独立收缩，避免滚动正文跳动。宽屏188px右栏与标题一起固定，不收窄整个论坛。
- 统一标题、回复标题、可点击回复计数、空态与输入框的间距、边框、圆角；根据用户最新要求改为灰色选中态、数量徽标、返回和输入焦点。保持浅灰/白主色，不添加装饰副标题。
- 五套人工字典新增简短回复标签和返回按钮提示；英文和日文返回文案缩短。
