# 社区升级差异清单

日期：2026-10-21。以当前源码和用户确认后的计划为准。

| 提示词要求 | 实际差距 | 阶段 |
| --- | --- | --- |
| 保留架构/数据/API/路径 | 已有；补可追踪迁移、源码基线、可恢复删除与发布校验 | M0 |
| 中文默认与账号语言偏好 | 当前仍按系统语言；五套人工字典已有，繁中保留 | M1 |
| 管理安全与举报工作流 | 基础后台已有；缺处理状态、禁言/封禁、审计查询 | M1 |
| 最新/热门/新帖/未读/无回复/已解决 | 最新/回复量热门/无回复已有；新帖未读和已解决依赖阅读、答案模型 | M2/M4 |
| 主题/楼层链接、进度、时间轴 | 缺稳定详情与楼层路径、服务端分页、账号阅读状态 | M2 |
| 全库搜索和多语检索 | 当前只搜已加载标题/摘要/作者；基础先做，全检索后做 | M2/M5 |
| 完整编辑器 | 新主题基础 Markdown、图片、预览已有；回复、编辑版本、多引用、灯箱待扩展 | M3 |
| 中日英韩帖子翻译 | 用户确认点击翻译，不能机器覆盖人工 UI；需原文版本、Markdown保护和权限 | M3 |
| 多草稿、历史、跨设备 | 单浏览器单草稿已有；多草稿和服务端同步后续做 | M6 |
| 反应/收藏/最佳答案/通知 | 尚缺；先稳定内容、事件、订阅和用户标识 | M4 |
| 分类/标签管理与资料 | 目录静态，资料仅基础账户页；稳定ID、后台和隐私待建 | M5 |
| SEO | 首页和电费已做；原文话题路径/可抓取HTML前移 | M2/M5 |
| 私信/等级/徽章/活动/Wiki/AI | 尚缺；按需求独立立项，不一次性开发 | M6 |
| 搬家清单/知识库 | 搬家入口为预留；后续模板、状态、正式内容与讨论关系 | M6 |
| 电费集成 | 已有工具，保留六个月限制与既有电价数据；分享后续独立设计 | 持续回归 |

M0 不更改默认语言，不开放机器帖子翻译，也不添加禁言、通知、私信或阅读状态。
