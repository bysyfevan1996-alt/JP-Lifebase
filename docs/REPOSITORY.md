# 专属代码仓库

仓库：<https://github.com/bysyfevan1996-alt/JP-Lifebase>。

本项目继续采用Node.js 24、内置HTTP和SQLite、静态前端，无需安装前端框架或数据库服务。

## 本地运行

```sh
npm start
```

服务默认只监听本机127.0.0.1:8797。独立预览设置自己的JPL_DATA_DIR；HTTP预览使用COOKIE_SECURE=0。不要将生产数据库或配置复制到仓库。没有邮件供应商配置时，不支持真实验证码投递；测试使用严格隔离的本地发件箱。

## 检查

```sh
node ops/check-i18n.mjs
node --test tests/*.test.mjs
python3 -B tests/installer_test.py
```

测试自行创建临时数据库、清除继承的邮件和翻译配置，不使用生产账号。浏览器视觉、手机键盘与辅助功能检查独立记录，不由自动测试代替。

## 内容与排除项

版本控制包含运行源码、前端、测试、官方电费资料、运维脚本和维护记录。排除运行数据库、环境文件、密钥、临时测试目录、生成发布包及已弃用的Sites预览元数据。官方资费资料是公开来源证据，不包含个人账单。

运行源码和官方证据关闭Git换行转换，保留发布清单及资料SHA-256所对应的原始字节；不要为消除CRLF提示而重写冻结迁移或重新计算官方证据摘要。

首次完整代码提交保留专属仓库已有的初始化历史，不强制覆盖远程。Git身份使用该GitHub用户名及隐私noreply地址，不将私人收件地址用作提交邮箱。

GitHub工作流在提交或PR时运行字典、Node和安装器检查；没有定时任务，不自动部署生产。实际GitHub执行结果需要在推送后确认，不能把本地通过称作远程检查通过。
