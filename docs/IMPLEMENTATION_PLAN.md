# 社区升级执行顺序

依据：[确认的实施计划](./COMMUNITY_UPGRADE_PLAN.md)。M0已完成，本轮实施M1；实际完成状态见IMPLEMENTATION_PROGRESS.md。

1. **M0 升级基线**：审计与完整源码快照 → 迁移账本 → 可恢复隐藏 → 源码清单/健康版本 → 备份副本迁移、恢复与候选服务预演 → 测试 → VPS 发布与检查。
2. **M1 语言和基础管理**：首次简中、保留五套人工字典、登录语言偏好；切换保留草稿/路由；举报状态、禁言/封禁、管理员审计查询。旧会话立即生效，重启保持，防止误封自己/最后管理员。
3. **M2 浏览阅读基础**：真正话题/回复路径、兼容旧 hash、服务端分页、轻量列表、基础全库搜索、稳定楼层、阅读/未读、原文 SEO。
4. **M3 编辑翻译**：复用现编辑器到回复，编辑版本与并发校验、结构引用、灯箱、点击翻译；原文语言/版本、Markdown结构、额度、失败回退与权限独立验证。
5. **M4 通知互动**：统一去重事件、订阅和已读，再接 @/引用/回复/反应；收藏、最佳答案、已解决筛选逐项发布。
6. **M5 检索与内容组织**：多语全文检索与短词回退、公开资料和隐私、目录后台、明确口径的统计、正式内容多语 SEO。
7. **M6 按需求扩展**：知识库、搬家清单、多草稿同步、私信等独立评估；私信先做权限、屏蔽和滥用约束。

每期保持电脑宽布局、手机独立适配和电费工具，先做隔离数据与权限验证，再发布；更新实施记录和维护 skill。M0 的旧结构基线冻结，未来变更新增迁移版本，不能编辑版本1以绕过校验。
