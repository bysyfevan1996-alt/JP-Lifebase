# Japan Life Base 社区首页

以 Teskas 首页结构为参考的独立品牌设计预览。浏览器直接运行，无安装和构建步骤。

## 已实现

- 56px 固定顶栏：菜单、品牌、搜索、筛选、注册和登录入口。
- 260px 固定侧栏：介绍、指南、推广块、可折叠分组、六个分类、工具。
- 灰色页面背景，24px 间距和面板内边距，白色大圆角面板。
- 最新/热门、232px 可隐藏公告、置顶摘要、独立话题卡片。
- 19 条原创示例话题，首屏加载12条，可继续加载。
- 分类与搜索组合筛选、清除、空结果、列表与详情往返。
- 手机抽屉、演示发帖/回复/收藏、AI助手交互示例。

## 文件

`dist/index.html`、`dist/styles.css`、`dist/app.js`、`dist/topics.js`、`dist/select-topics.js`。

## 配置

`app.js` 的 `state.showBanner` 控制横幅默认显示。页面搜索框中的筛选入口也可以切换。

## 运行

用静态 HTTP 服务指向 `dist`。ES Modules 需要通过 HTTP 访问。

## 范围

当前是首页及浏览流程演示。主题、作者、计数、时间均为示例；账号、发帖和回复没有真实后端，多人不能同步。助手提供本地示例回复，没有调用 AI 服务。生产论坛仍需真实账号、数据库、反垃圾和管理系统。
